새 호스팅에는 사이트 ZIP만 업로드합니다. 사이트 루트(/)용이며 GitHub Pages의/meowwoof-server/경로용 빌드와 다릅니다. 전체 자료 묶음을 웹사이트로 올리지 마세요. 새 호스팅·DNS·광고는 연결하지 않았습니다.

AI 모의 전투이며 실시간 멀티플레이가 아닙니다. WASD는 기존 속도/선회, Shift 상승, Space 하강, 마우스 왼쪽 누르기로 연사합니다. 최대20초·100발·명중당2점, 각 기체 획득/손실 최대50점. 이번 판의 최종 순위와 공유에 반영하고 기존 최고/최근 비행/개인 일일 및 공식 점수는5라운드 폭격 기준으로 보존합니다.

파일 SHA256은SHA256SUMS.txt에서 확인할 수 있습니다. 최신 개발 원본·비밀키·소스맵은 이 브랜치에 포함하지 않았습니다. 실행 JavaScript는 난독화 빌드이며 암호화나 부정행위 차단을 보장하지 않습니다. 이전1.10.0 ZIP도 기존 링크를 위해 보관합니다.
