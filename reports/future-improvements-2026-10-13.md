# BOMB RUN 추가 개선 보고서

작성일: 2026-10-13 · 대상: 1.1.0 검토 이후

**아래 제안은 보고서만 작성했으며 이번 업데이트에 구현하지 않았습니다.**

## 이번 검토의 기준

1.1.0에서 속도에 맞춘 프로펠러 회전·엔진 박동음, 투하·귀여운 착탄음, 불규칙 잉크/물 번짐과 찢김, 비행·낙하 중 목표 전체 비노출, 기체 아래에서 시작하는 짧은 낙하 궤적을 반영했습니다. 자동 테스트 31개와 1,000개 시드 검사는 개발 환경에서 통과했습니다. 공개 배포물의 5라운드 완주, 모바일 터치, 실제 Web Audio 출력·효과음 생성·음소거, 소스 노출 감사는 GitHub CI에서 통과했습니다. 실제 Android/iPhone 기기 청취·성능 테스트는 아직 별도입니다.

최신 원본은 공개 저장소에 올리지 않고 현재 클라우드 작업 공간과 보존 아카이브에 유지했습니다. 사이트에는 난독화된 실행 파일만 게시합니다. 원본 파일·소스맵·게임 상태 디버그 객체는 최신 배포에서 제외했습니다. 이전에 공개된 버전의 소스 이력은 남으며, 브라우저가 실행하는 코드 자체는 개발자 도구로 분석할 수 있습니다. RC4 문자열 처리와 난독화는 열람을 어렵게 하는 조치이지 해킹 방지나 비밀 보관 수단은 아닙니다.

## 1. 신뢰할 수 있는 온라인 경쟁 — 우선순위 높음

현재 친구방·일일 도전은 로컬 모드입니다. 공식 순위가 필요해지면 서버가 방 참여자, 라운드 시드·바람·출발 슬롯, 진행 시간과 제출 여부를 관리하고 입력 로그로 착탄과 점수를 재계산해야 합니다. 클라이언트가 보낸 점수는 그대로 저장하지 않는 것이 핵심입니다.

공정한 공개 시점을 위해 현재 라운드만 제공하고, 제출 중복 방지·요청 제한·인증을 추가하는 것을 권장합니다. 그래도 지도 캡처나 자동 조종까지 완전히 막을 수 있다고 보장해서는 안 됩니다.

완료 기준: 변조 점수·초과 속도·시간 초과 투하·중복 제출을 서버에서 거절하고 동일 로그의 점수를 재현할 것.

## 2. 비공개 원본 저장소와 원본 보존 — 우선순위 높음

최신 원본은 현재 환경의 로컬 전용 work 브랜치와 `/workspace/onboarding/bomb-run-source-v1.1.0.tar.gz`에 보존했습니다. 이 work 브랜치를 공개 origin으로 push하면 원본이 공개됩니다. 현재 GitHub 연결은 비공개 저장소 생성과 Actions Secrets 관리 요청을 403으로 거절했습니다. 별도 비공개 원본 저장소에 최신 소스를 안전하게 이관하는 작업은 완료되지 않았습니다.

후속으로 비공개 원본 저장소를 준비하고 GitHub 연결 앱의 접근 권한을 설정한 뒤, 개발 소스와 공개 배포물을 분리해 관리하는 것을 권장합니다. 빌드는 비공개 저장소에서 수행하고 배포에는 최소 권한을 사용해야 합니다. 현재 공개 자동화는 완성된 배포물 검증이며 비공개 원본의 자동 빌드까지 제공하지 않습니다.

완료 기준: 새 개발 환경에서 원본을 안전하게 복원할 수 있고, 공개 저장소·사이트·로그·검증 아티팩트에 최신 원본이나 비밀키가 포함되지 않을 것. 이미 공개된 과거 소스의 복사본까지 회수할 수는 없습니다.

## 3. 실제 모바일 기기의 오디오·성능 검증 — 우선순위 높음

Android Chrome, iPhone Safari에서 가로/세로 전환, 주소창 높이 변화, 터치 동시 입력, 무음 스위치·블루투스, 앱 전환 후 오디오 재개를 확인하는 것을 권장합니다. 에뮬레이션의 성공은 실제 기기의 청취 품질이나 FPS 보증과 다릅니다.

완료 기준: 실제 기기에서 첫 입력으로 사운드가 활성화되고 음소거가 동작하며, 프레임이 낮아져도 조작·20초 제한·착탄 판정이 일관될 것.

## 4. 새 낙하 방식에 맞춘 난이도·점수 보정 — 우선순위 중간

목표를 숨기고 전진 이동을 줄인 변경은 기억·탐색 능력의 비중을 높입니다. 초보/숙련자별 미투하율, 목표 탐색 성공률, 착탄 오차와 라운드 점수 분포를 수집해 지도 손상량과 점수 거리 스케일을 조정하는 것을 권장합니다. 휴리스틱 난이도 점수가 사람의 실제 난이도와 같다고 가정하지 않아야 합니다.

완료 기준: 어느 출발 슬롯에서도 접근 불가능한 라운드가 없고, 특정 시드나 방향에 점수 이득이 편중되지 않을 것.

## 5. 짧은 연습 안내와 결과 복습 — 우선순위 중간

연습 모드에만 지도 기억·선회·바람 읽기·기체 아래 투하를 알려주는 짧은 안내를 제공하고, 결과에서 투하 지점과 착탄 지점의 차이를 설명하는 방식을 권장합니다. 경쟁 비행 중 정답 깃발이나 착탄 예상점을 다시 표시하는 방식은 피해야 합니다.

완료 기준: 처음 플레이한 사용자도 한 번의 연습으로 조작과 낙하 지연을 이해하고, 경쟁 모드에는 추가 정답 단서가 나타나지 않을 것.

## 6. 음량 조절과 사운드 접근성 — 우선순위 중간

엔진음과 효과음의 음량을 따로 조절하고, 효과음을 듣기 어려운 환경에서도 투하·착탄을 이해할 수 있는 짧은 시각 신호를 검토할 수 있습니다. 현재의 전체 사운드 ON/OFF는 유지하면서 선택권을 넓히는 제안입니다.

완료 기준: 작은 스피커·이어폰에서 엔진음이 착탄음을 가리지 않고, 음량 설정이 다음 방문에도 유지될 것.

## 7. 그래픽 최적화와 가독성 — 우선순위 중간

실제 기기 측정 결과를 바탕으로 먼 나무/마을의 표시 밀도와 픽셀 비율을 조절하는 것을 권장합니다. 훼손 지도는 작은 화면에서도 풍차·탑·강 합류 등 필수 단서와 목표 마커를 구별할 수 있어야 합니다. 아트 방향은 현재 로우폴리 미니어처 분위기를 유지하는 것이 좋습니다.

완료 기준: 품질을 낮춰도 지형 판별에 필요한 랜드마크가 사라지지 않고, 터치와 HUD를 가리지 않을 것.

## 제안 순서

원본 보존·비공개 저장소 권한 정리와 실제 기기 검증을 먼저 진행하고, 공식 온라인 순위가 필요하면 서버 검증을 추가합니다. 이후 실제 플레이 데이터를 기준으로 난이도·연습 안내·음량·성능을 보정하는 순서를 권장합니다. 이 제안에 따른 기능 변경은 이번 버전에 포함하지 않았습니다.
