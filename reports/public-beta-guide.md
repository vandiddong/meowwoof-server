# 붐케르크 무료 웹 베타 공개 안내

현재 공개 링크: https://vandiddong.github.io/meowwoof-server/?v=1.10.0

현재 사용할 수 있는 기능은 자유 비행, 브라우저 개인 기록, 5라운드 결과 이미지 저장·공유입니다. 순위표의 AI는 모의 경쟁입니다. 공식 일일 순위·Google 로그인·광고·결제는 아직 공개 연결되지 않았습니다.

바로 공개하는 방법:
1. 링크를 카카오톡·디스코드·커뮤니티 게시글·인스타그램 프로필에 붙여 넣습니다. 설치는 필요 없습니다.
2. 처음에는 지인 10~20명에게 새 지도 기억과 조작, 폭탄의 속도가 어떻게 느껴지는지 확인합니다. 게임의 공유 이미지를 저장해 게시할 수 있습니다. Instagram 자동 게시 기능은 제공하지 않습니다.
3. 완주하는지, 바로 재도전하는지, 다음 날 다시 오는지 직접 피드백을 모은 뒤 공개 범위를 넓힙니다. 현재 방문자·재방문 분석 SDK가 없으므로 자동 집계가 된다고 안내하지 않습니다.

붙여 쓸 소개 문구:
“처음 보는 지도를 10초 동안 기억하고, 하늘에서 한 발로 맞혀보세요. 기억력과 비행 정확도로 겨루는 붐케르크 무료 웹 베타! 5라운드 결과를 이미지로 공유할 수 있어요.”

목표 위치 업데이트: ±135 → ±360. 전체 맵 1,200의 중앙 60% 폭까지 배치하며, 원래 중앙 영역 밖을 실제로 사용합니다. 16개의 목표 배정 구역을 정하고 지형 재시도 중 유지합니다. 출발점은 같은 거리의 안전한 호에서 골라 바깥 목표가 탈락하면서 중앙으로 몰리는 현상을 막습니다. 극단적인 맵 가장자리까지 확장하지 않습니다. 비행 20초, 빠른 착탄 연출과 기존 폭탄 물리은 유지합니다.

정식 랭킹 공개에 필요한 다음 준비:
- 운영자가 관리하는 HTTPS API와 지속 데이터 저장소. Node 24/SQLite 서버를 실행하고 DB와 .seed-key를 함께 비공개 백업합니다. 무료 임시 파일 시스템에 영구 순위를 맡기지 않습니다.
- 실제 API URL을 프런트 VITE_COMPETITION_API_URL에 연결하고 CORS origin, 요청 제한, 백업 복원, 한 도전 전체 입력 검증을 확인합니다.
- Google 로그인은 OAuth 클라이언트 ID/승인 origin 설정 후 실제 계정으로 검사합니다. 토큰이나 비밀키를 채팅에 보내지 않습니다.
- 운영자 charlielimJR / 문의 vandiddong@gmail.com은 반영돼 있습니다. 개인정보 보유·삭제 절차와 최종 정책, 실제 Android/iPhone 검증은 남아 있습니다.

수익화 전에는 상업 운영을 지원하는 정식 호스팅·도메인을 마련하고 광고/결제 승인을 진행합니다. 외형 상품을 먼저 검토하고 공식 추가 도전권·목표 힌트는 판매하지 않습니다. 현재 구매 버튼이나 광고는 없습니다. 비공개 원본 저장소 연결도 계속 필요한 준비입니다.

1.4.1 지도 안내: 기억할 착탄 목표는 선명한 빨간 깃발과 십자선으로 표시하고 느린 점멸 링으로 강조합니다. 움직임 줄이기/OS 설정에서는 고정 표시합니다. 비행 중 목표 표시는 숨기므로 지형 기억으로 찾아야 합니다. 작은 가로 화면에서도 지도 전체가 들어오도록 조정했습니다. 무료 공개 베타는 GitHub Pages를 유지합니다. GitHub Pages는 정적 호스팅이며 자체 Node 서버/DB를 실행하지 않습니다. 로그인·정식 랭킹·상업 서비스 도입 시 별도 서버와 적합한 프런트 호스팅으로 옮깁니다. 정책 참고: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

1.5.0: 처음 비행 전 5쪽 가이드북으로 지도 암기·가림물·조작·한 발 투하·점수를 설명합니다. 메뉴에서 다시 볼 수 있습니다. 지도10초/비행20초, 진한 빨강·노랑·파랑 지붕, 사과·메모·찻잔 가림물과 더 후한 점수표를 적용했습니다. 새 점수표 개인 기록은 별도로 쌓으며 이전 기록 데이터는 지우지 않습니다.

1.6.0: 맵 전체 16구역을 같은 확률로 선택해 목표의 중앙 편향을 줄였습니다. 1,000개 검사에서 중앙 2×2는 71%→27.5%, 바깥 12칸은 72.5%입니다. 목표 안전 범위 ±360, 지도10초·비행20초·점수표·조작은 유지합니다. 1,200개 고정 물리 접근 검사를 통과했으며 인간 체감 난이도는 별도 확인이 필요합니다.

1.7.0: 각 투하 결과에 목표·착탄점·투하 위치의 위에서 본 그림과, 투하 순간 진행 방향을 기준으로 한 앞뒤/좌우 오차를 보여줍니다. 다음에는 접근 방향 또는 투하 시점을 어떻게 조절할지 안내합니다. 미투하 안내도 제공합니다. 점수/기록/제한 시간/목표 배정은 유지하며, 비행 중에는 분석 정보가 나타나지 않습니다.

1.8.0 조작 훈련: 첫 시작에서는 가이드북 뒤에서 훈련/건너뛰기를 선택합니다. 선회와 감속을 실제로 해본 뒤, 빨간 목표와 하늘색 예상 착탄점을 보며 투하 타이밍을 익힙니다. 준비 버튼 전에는 마지막 비행 시계가 시작하지 않습니다. 결과에서 마지막 투하를 다시 연습하거나 실전으로 이어갈 수 있습니다. 메뉴의 조작 훈련으로 처음부터 다시 할 수 있습니다. 훈련은 개인·일일·공식 기록에 반영하지 않습니다. 일반/공식 비행은 목표를 기억해 찾는 기존 방식입니다.

## 선택형 베타 플레이 점검

메뉴의 **플레이 점검**에서 설명을 읽고 기기 내 저장에 동의하면 그 뒤 시작한 자유 비행·개인 일일 게임부터 집계합니다. 조작 훈련·연습·공식 도전은 제외합니다. 게임 시작은 실제 첫 지도 공개 시점, 완주는 다섯 라운드를 끝내고 최종 결과를 연 시점입니다. 진행 중·중단한 게임도 시작에 포함하므로 점검은 결과를 닫고 확인하는 것이 좋습니다.

재도전은 같은 탭에서 완주한 뒤 다시 시작한 횟수이며, 탭을 새로 열면 이전 재도전 기회는 이어지지 않습니다. 다음날 다시 플레이는 한국 날짜로 전날과 오늘 모두 시작 기록이 있는 날짜 수입니다. 기기별 최근30일 합계이며 전체 이용자 DAU/유지율·공식 순위를 뜻하지 않습니다. 브라우저 저장소는 수정/삭제될 수 있습니다.

실제 Android/iPhone 점검 시 사운드·동시 터치·회전·복귀를 직접 확인하고 일반 게임을 완주한 뒤 점검 화면과 프레임 합계를 확인합니다. 원하면 점검 파일을 저장해 내용을 확인한 뒤 운영자에게 직접 전달합니다. 사이트가 자동 수집하지 않습니다. 같은 브라우저의 반복 내보내기는 기간이 겹치므로 합산하면 중복됩니다. 운영자는 자료를 요청하기 전에 목적/보유 기간을 안내하고, 한 점검 기간에 한 브라우저당 최종 파일 하나만 받는 방식으로 사용해야 합니다. 다운로드만으로 전송·수집이 완료됐다고 간주하지 않습니다.

전체 이용자 측정·동의된 자동 수집, 실제 기기의 FPS·소리 검증은 완료되지 않았습니다. 이번 기능은 직접 베타 점검을 할 수 있는 준비이며 광고 SDK를 추가하지 않습니다.

## 나의 비행 기록과 다음 목표

자유 비행·개인 일일 도전의5라운드를 완주하고 최종 결과를 열면 이번 업데이트 이후 최근20판을 이 브라우저에 보관합니다. 기존 최고기록은 유지하며 예전 기록을 추측해 채우지 않습니다. 훈련·연습·공식 기록은 이 목록에 넣지 않습니다.

결과 화면에서 직전 완주 판과 비교하고 이번 점수 다음의50점 단위 목표를 확인합니다. 예:172점이면200점,450점이면500점.500점 만점이면500점에 다시 도전하며501점 같은 불가능한 목표는 제시하지 않습니다. 지도마다 조건이 달라 점수 차이만으로 실력 변화를 판단하지 않습니다. 메뉴/결과의 나의 비행 기록에서 최근5판 점수와 최근20판의 라운드 점수를 확인하고 새 자유 비행을 시작할 수 있습니다.

최근 기록만 지워도 기존 최고·일일·설정·플레이 점검 통계는 유지합니다. 저장소를 사용할 수 없으면 이번 결과는 표시하고 최근 기록 저장에 실패했음을 알립니다. 기록은 기기 내 개인 기능이며 운영자에게 자동 전송되지 않고 점검 파일에도 들어가지 않습니다. 실제 재도전율이 높아졌다는 검증 결과는 아직 없습니다.
