# 붐케르크1.11.0 — 100발 AI 도그파이트

플레이: https://vandiddong.github.io/meowwoof-server/?v=1.11.0

5라운드 폭격 뒤 AI4대와 최대20초의 공중전을 진행합니다. 고정 추적 시점·중앙 조준선·회전하는 총열·발사체·연사/명중 효과음·적 점수 표시를 제공합니다. PC는W/S 속도, A/D 선회, Shift 상승, Space 하강, 마우스 왼쪽 누르기 연사입니다. 모바일에는 상승/하강/발사 버튼을 추가했습니다. 폭격 중Space 투하는 유지합니다.

100발을 소진하고 남은 자기 발사체의 판정이 끝나거나20초가 지나면 결과를 즉시 표시합니다. 120Hz 고정 간격의 선분 충돌로 빠른 탄환의 관통 누락을 줄입니다. 명중당2점을 상대에게서 이동시키며, 각 기체의 총 획득/손실은 각각50점, 점수는0~500점입니다. 상대의 실제 잔여 점수만 이동하므로 전투 전후 점수 총합이 같습니다. AI도 같은 탄약·발사체·충돌·점수 규칙을 사용합니다.

이번 판의AI 순위·공유 이미지·수동 비행 로그에는 공중전 결과를 포함합니다. 기존 최고기록·최근 비행·개인 일일 기록은5라운드 폭격 점수로 보존합니다. 클라이언트AI 공중전 점수를 공식 서버에 제출하지 않습니다. 공식 서버의 기존 폭격 리플레이/점수 규칙은 유지합니다. 실제 멀티플레이는 추가하지 않았습니다.
