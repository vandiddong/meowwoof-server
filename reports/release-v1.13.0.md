# 붐케르크1.13.0 — 기억 폭격 / 회피·격추 모드 분리

플레이: https://vandiddong.github.io/meowwoof-server/?v=1.13.0

첫 화면에서 기억 폭격과 회피·격추를 선택합니다. 폭격은 기존10초 지도·20초 비행·5라운드 후 즉시 최종 점수와 결과 공유로 끝납니다. 점수 쟁탈 피날레는 제거했습니다.

공중전은 같은 지형 생성기로 만든 강·마을·산 위에서 CPU1대와 바로 시작하는60초 출격입니다. 내 체력6/적 체력4, 명중25점·격추200점·생존초당5점입니다. 격추 후2초 뒤 새CPU가 접근하며100발 탄창은1.5초에 자동 재장전합니다. 지형과 건물/나무의 단순화한 충돌 범위가 탄환을 막으며 지형 접촉 시 플레이어에게 피해를 줍니다. CPU는0.8초 발사 예고 후 예상 진행 위치를 향해 고정 방향의 짧은 탄막을 발사하므로 방향·고도를 바꾸어 회피할 수 있습니다. 화면 밖 적 방향, 피격/명중과 격추 효과를 표시합니다.

PC마우스/모바일드래그로 기수·고도를 조종하고 자동 전진합니다. 조준선 근처 적에게 실제 탄환을 자동 발사하고 자동사격을 끄거나 클릭/FIRE로 직접 사격할 수 있습니다. 화면 위Ⅱ메뉴는 시간과 입력을 멈추고 계속·재출격·모드 선택을 제공합니다. 모바일은Esc가 필요 없으며PC도 기본 포인터 잠금이 없어 메뉴를 바로 누를 수 있습니다. 작은 세로 화면은 카메라를 뒤로 당겨 시야를 확보합니다.

공중전 최고점은 별도 브라우저 항목에만 저장합니다. 폭격 최고점/최근기록/개인일일/선택형통계/공식서버/공유카드와 합치지 않습니다. 실제 멀티·광고·유료서비스는 연결하지 않았습니다.

자동 테스트127개(새 공중전10개 포함), 타입 검사·Pages빌드·원본노출 검사를 통과했습니다. 공개전체브라우저검증 결과는 배포 후 이 문서에 추가합니다. 모바일브라우저 에뮬레이션은 실제Android/iPhone검증과 다릅니다. 최신 원본은 비공개 환경의 아카이브와Git bundle로 보존하고 공개 저장소에는 배포물·검증 도구·설명만 반영합니다.
