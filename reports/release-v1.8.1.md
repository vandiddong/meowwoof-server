# Boomkerque 1.8.1: learn one drop by doing

Play: https://vandiddong.github.io/meowwoof-server/?v=1.8.1

An optional three-step flight lesson follows the first local guide: steer with A/D or arrows, brake with S or minus, then watch a red target and cyan predicted-impact ring while releasing one bomb. The menu’s new training action repeats the whole lesson. A first-run offer can be skipped; completion/skipping is saved locally to avoid repeated prompts. It resumes the requested free/practice/local-daily mode. Official starts bypass the offer, so their server clock is not delayed.

Control-learning steps have no failure clock. The final approach remains frozen until the ready action, then uses the same20-second RoundSimulation, retained airspeed, weighted belly release, fixed120Hz physics and4× post-drop presentation as regular play. The course is fixed and separate. Prediction uses the actual collision integrator; the same release lands at the same point. The result reuses the existing geometric feedback, handles timeout honestly, and can restart only the approach for another timing attempt. Training never updates a personal/daily/ranked best or submits a server score. An already completed status survives skipping a later repeat.

A wider training-only camera keeps the target below the portrait coach and above the instruments. The renderer reveals target/predicted ring only through an explicit training flag and forcibly hides prediction in regular rendering. Normal map memorization10seconds, flight20seconds, scoring, target distribution and stored records remain unchanged. Settings are not changed to force normal trajectory help. Closing the first offer or returning home clears its dialog and focus/inert state.

Validation:81 automated tests, including seven lesson lifecycle/physics tests and renderer concealment and portrait camera-framing tests; type checking/build/source-exposure audit. Tests cover actual steering/braking requirements, paused readiness, retained speed, identical keyboard/touch input, prediction equality, single release,30/60/144FPS, timeout/retry and unchanged course/config. Browser checks cover first-guide offer, skipping with the requested mode preserved, keyboard and touch lessons, readiness, close impacts, excluded personal records, retry/timeout, resuming normal flight, repeat-from-menu and no repeated prompt. Public HTTPS results are recorded after deployment. Physical phones remain untested.
