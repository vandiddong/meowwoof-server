Count a start only after the guide/training offer is resolved and the actual game begins. Count completion only after all five rounds and the final-result action. Unfinished/in-progress starts remain in the denominator. A retry is one subsequent eligible start after a completed game in the same tab, including a menu detour, without extending the opportunity across reloads. Next-day play counts a Korean calendar date with play starts both that day and the previous day; it is not a population D1 retention rate. Game-round/completion/frame aggregates belong to their start-date cohort so midnight cannot create completions without starts. Expired dates are excluded on read/export and physically pruned on the next write.

Flight/bomb frame timing is buffered in memory, measured only with a visible document and closed dialog, and flushed at phase/lifecycle boundaries. The frame loop does not write storage. No frames are sampled in training/menus/settings/background/official mode. Export includes only dates, aggregate counts and frame sums; it excludes names/emails/accounts/IDs/user agents/screen sizes/maps/coordinates/input logs/scores. Storage failure never blocks gameplay. Withdrawal discards pending frames and removes only this statistics key; settings/bests survive. Another tab's withdrawal is respected before future writes. The modal supports focus trapping, Escape, background inertness and small-screen scrolling. Result overview invalidation on viewport/quality changes also preserves the static-background optimization after rotation.
